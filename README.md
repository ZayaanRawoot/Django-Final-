A full-featured job listings web application built with Django, Python, HTML, CSS, and JavaScript. This app allows users to browse, search, and apply for jobs, while employers can post and manage job listings.

Features

User Authentication: Users can register, log in, and manage profiles.

Job Listings: Employers can create, update, and delete job postings.

Search & Filter: Users can search for jobs by title, location, or category.

Responsive Design: Mobile-friendly UI using HTML, CSS, and JavaScript.

Database Management: Backend powered by Django ORM for secure data handling.

Technologies Used

Backend: Django, Python

Frontend: HTML5, CSS3, JavaScript

Database: SQLite (default Django DB)
